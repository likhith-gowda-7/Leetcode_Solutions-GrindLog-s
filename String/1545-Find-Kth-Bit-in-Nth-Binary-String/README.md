## 📝 Problem Description

Given two positive integers `n` and `k`, the binary string `S_n` is formed as follows:

	- `S_1 = "0"`

	- `S_i = S_i - 1 + "1" + reverse(invert(S_i - 1))` for `i > 1`

Where `+` denotes the concatenation operation, `reverse(x)` returns the reversed string `x`, and `invert(x)` inverts all the bits in `x` (`0` changes to `1` and `1` changes to `0`).

For example, the first four strings in the above sequence are:

	- `S_1 = "0"`

	- `S_2 = "0**1**1"`

	- `S_3 = "011**1**001"`

	- `S_4 = "0111001**1**0110001"`

Return *the* `k^th` *bit* *in* `S_n`. It is guaranteed that `k` is valid for the given `n`.

 

Example 1:**

```

**Input:** n = 3, k = 1
**Output:** "0"
**Explanation:** S_3 is "**0**111001".
The 1^st bit is "0".

```

Example 2:**

```

**Input:** n = 4, k = 11
**Output:** "1"
**Explanation:** S_4 is "0111001101**1**0001".
The 11^th bit is "1".

```

 

**Constraints:**

	- `1 <= n <= 20`

	- `1 <= k <= 2^n - 1`

## 🧠 Solution Explanation

**Intuition**
The solution uses a recursive approach to generate the binary string `S_n` and then returns the `kth` bit. The key insight is that the binary string `S_n` can be generated by concatenating the previous string with its reverse and inverted version, which allows us to calculate the `kth` bit directly.

**Approach**
1. Initialize the previous string `prev` to "0" and the current length `curr_len` to 1.
2. Decrement `n` by 1 to simplify the loop condition.
3. While `n` is greater than 0 and `curr_len` is less than `k`, perform the following steps:
   1. Initialize an empty string `curr` to store the inverted and reversed version of `prev`.
   2. Iterate over each character `val` in `prev` and append the inverted character to `curr`.
   3. Append "1" and the reversed `curr` to `prev`.
   4. Update `curr_len` to `curr_len * 2 + 1`.
   5. Decrement `n` by 1.
4. Return the `kth` bit of `prev`.

**Time Complexity**
O(n * log(n)) where n is the input number. This is because we are generating the binary string `S_n` up to length `n * log(n)` and performing constant time operations for each bit.

**Space Complexity**
O(n * log(n)) where n is the input number. This is because we are storing the binary string `S_n` up to length `n * log(n)`.

**Key Insight**
The key insight is that the binary string `S_n` can be generated by concatenating the previous string with its reverse and inverted version, which allows us to calculate the `kth` bit directly. This insight simplifies the problem and enables us to solve it efficiently.
